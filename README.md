# Computabilidad y Algoritmia

Prácticas de la asignatura Computabilidad y Algoritmia (CyA) · Universidad de La Laguna · Grado en Ingeniería Informática.

## Contenido

| Carpeta | Tema |
|---|---|
| `P02` | Alfabetos, cadenas y lenguajes en C++ |
| `P04_regex` | Analizador de código con expresiones regulares (comentarios, bucles y variables) |
| `P05` | Autómatas finitos deterministas y no deterministas en JFLAP (`.jff`) |
| `P08_Chomsky` | Transformación de gramáticas a forma normal de Chomsky |
| `P09_Turing` | Máquinas de Turing y multicinta en JFLAP (`.jff`) |
| `preparacion-examen` | Fragmentos de código de preparación del examen |

## Compilación

Las prácticas en C++ incluyen un `Makefile`:

```bash
make
```
